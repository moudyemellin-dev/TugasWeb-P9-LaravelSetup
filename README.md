# Tugas Rutin 9 - Laravel Setup

Project ini dibuat untuk memenuhi **Tugas Rutin 9 Pemrograman Web** menggunakan framework Laravel.

## Identitas

- Nama: Moudy Emellin
- Mata Kuliah: Pemrograman Web
- Project: Tugas Rutin 9 - Laravel Setup
- Framework: Laravel
- Database: MySQL

## Fitur

- Laravel Routing
- Blade View
- Controller
- Model dan Migration
- Koneksi Database MySQL
- Data dinamis menggunakan array dari route
- Styling menggunakan Tailwind CSS CDN
- Bonus route parameter `/hello/{nama}`

## Route

| URL | Keterangan |
|---|---|
| `/` | Halaman Home |
| `/about` | Halaman About |
| `/contact` | Halaman Contact |
| `/hello/{nama}` | Bonus route parameter |
| `/welcome` | Laravel Welcome Page |
